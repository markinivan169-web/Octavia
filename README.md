# OCTAVIA. / Black Edition — 2010

Персональная одностраничная презентация Škoda Octavia A5 Facelift.

**В полученном приложении была только текстовая спецификация, без фотографии.** Поэтому в проект не добавлены чужие фотографии, выдуманные изображения автомобиля или приблизительная 3D-геометрия. До подключения снимков работает типографическая версия. Чтобы закончить центральную автомобильную композицию и проверить соответствие внешности, необходимо добавить исходное фото конкретного автомобиля.

## Запуск

Требуется Node.js 22.12+ (проект проверен с Node.js 26).

```sh
npm ci
npm run dev
```

Откройте адрес из терминала, обычно `http://127.0.0.1:5173`.

```sh
npm run build
npm run preview
```

`build` проверяет TypeScript и создаёт готовый статический сайт в `dist/`. Не открывайте `index.html` двойным щелчком: используйте HTTP-сервер.

## Ваши фотографии

Для быстрого просмотра нажмите «Выбрать фотографии» в гараже. JPEG, PNG, WebP и AVIF до 30 МБ каждый; максимум 20 снимков. Они открываются через локальные object URL, никуда не отправляются и исчезают после перезагрузки. Можно добавлять несколько снимков за раз. Сначала проверяется возможность декодировать изображение.

Для постоянного сайта положите фотографии в `public/images/` и заполните **единую конфигурацию `src/config.ts`**:

```ts
photos: [
  {
    id: 'front',
    src: '/images/front.webp',
    alt: 'Моя чёрная Škoda Octavia A5 Facelift, передний ракурс',
    title: 'Передний ракурс',
    view: 'front',
    objectPosition: '50% 50%',
  },
  {
    id: 'side',
    src: '/images/side.webp',
    alt: 'Тот же автомобиль сбоку',
    title: 'Профиль',
    view: 'side',
  },
  {
    id: 'rear',
    src: '/images/rear.webp',
    alt: 'Тот же автомобиль сзади',
    title: 'Задний ракурс',
    view: 'rear',
  },
  {
    id: 'wheel',
    src: '/images/wheel.webp',
    alt: 'Крупный план пятиспицевого диска',
    title: 'Детали',
    view: 'detail',
  },
]
```

Пути в примере — инструкция, эти файлы не включены. Для Netlify/Vercel размещайте сайт в корне домена. Для размещения в подпапке скорректируйте пути публичных файлов.

Главный снимок — первый `front`, либо первое доступное фото. Порядок истории: передний вид → профиль → детали → задний вид → общий финал. Каждый промежуточный ракурс появляется только при наличии соответствующего снимка. С одним снимком доступны приближение и финал; боковой или задний вид не выдумываются. В фотопросмотре отсутствует фиктивный 360°-поворот.

Для лучшего результата используйте горизонтальные фотографии одного автомобиля, шириной примерно 2000–2600 пикселей, желательно WebP/AVIF до 500 КБ. Для студийного первого экрана подходит подготовленный снимок на тёмном фоне или прозрачный PNG/WebP. Передний вид должен занимать основную часть кадра. На мобильных устройствах исходный снимок в истории показывается целиком, без обрезки автомобиля.

### Подписи деталей

У каждой фотографии можно указать `hotspots`. Координаты `x` и `y` — проценты ширины и высоты исходного изображения. После подключения референса отмерьте их по настоящим деталям; пример схемы:

```ts
hotspots: [{
  id: 'headlight', title: 'Передняя оптика',
  text: 'Оригинальная оптика рестайлинговой Octavia A5.',
  x: 25, y: 60,
}]
```

Эти примерные координаты не добавлены в рабочую конфигурацию. Подписи открываются мышью, касанием и клавиатурой; перемещаются и масштабируются вместе с фото.

### Освещение и фары

«Свет студии» управляет окружающим светом виртуального фотостенда, а не физическим освещением внутри исходной фотографии. Управление фарами появляется только если у выбранного фото есть `headlightsSrc`: путь к реальному снимку того же ракурса с включёнными фарами. Оба снимка должны быть одинаково кадрированы. Фальшивые световые пятна на оптику не накладываются.

## Характеристики

Год, кузов, модель, цвет и номер заданы в `src/config.ts` по тексту задания. Двигатель, коробка, привод, мощность и пробег изначально `null`: они не выводятся в интерфейс. Укажите реальные значения строками с единицами, например `mileage: '… км'`, только после подтверждения. Все поля настраиваются в одном месте.

## Структура

```text
src/
  config.ts                   Автомобиль, снимки, подписи, характеристики
  App.tsx                     Сборка страницы, локальный выбор снимков
  styles.css                  Дизайн, адаптивность, reduced motion
  hooks/useMotion.ts          Lenis + GSAP, вступление, раскрытие блоков
  components/
    Header.tsx                Меню и якорная навигация
    Hero.tsx                  Первый экран и реакция на курсор
    Story.tsx                 Pinned scroll-сцены с scrub
    Garage.tsx                Фото, выбор, zoom, pan, подсветка
    Specifications.tsx        Только подтверждённые данные
    Gallery.tsx               Галерея, модальный полноэкранный просмотр
    Primitives.tsx            Подписи, изображения, магнитные кнопки
public/fonts/                 Локальные шрифты и OFL-лицензии
public/images/                Ваши фотографии
```

## Дизайн и движение

Палитра: `#08090B`, `#141619`, `#F5F5F5`, холодное серебро. Oswald для крупного автомобильного заголовка, Manrope для интерфейса и русского текста. Визуальный акцент — автомобиль на фоне крупной типографики; без одинаковых карточек и маркетинговых метрик.

React + TypeScript + Vite, GSAP / ScrollTrigger и **только Lenis** как движок плавной прокрутки. Обычный CSS без дополнительной системы компонентов. Three.js не установлен: точной модели автомобиля не предоставлено. Анимация автомобиля в `Story` отделена от анимации интерфейса в `useMotion`. GSAP и Lenis синхронизированы одним ticker; обработчики, media contexts и анимации очищаются при размонтировании. Движение преимущественно через transform/opacity. Изображения ниже первого экрана загружаются лениво.

При `prefers-reduced-motion: reduce` нет Lenis, pin/scrub, параллакса, вступительных и магнитных анимаций: история становится обычной последовательностью статических секций. На сенсорных экранах нет реакции камеры на наведение. Масштабирование доступно кнопками и ползунком; при увеличении снимок можно перемещать пальцем. Галерея использует нативный `dialog` с фокусом внутри, Escape, стрелками и возвратом фокуса. Скрытые технические значения не попадают в публичную страницу.

Без JavaScript доступна текстовая информация об автомобиле; интерактивная презентация требует JavaScript.

## Развёртывание

- **Netlify:** импортируйте проект. `netlify.toml` уже задаёт `npm run build` и папку публикации `dist`. Можно также загрузить готовую папку `dist` вручную.
- **Vercel:** импортируйте проект, Framework Preset — Vite, Build Command — `npm run build`, Output Directory — `dist`.

Сервер, ключи, база данных и переменные окружения не нужны. Внешние сетевые запросы приложением не выполняются: шрифты локальные. Сайт не опубликован автоматически; подготовлен локальный проект и статическая сборка для выбранного вами хостинга.

## Проверка

`npm run build` завершён успешно: строгая проверка TypeScript и production-сборка Vite. В браузере проверены размеры 390 × 844, 768 × 1024 и 1440 × 900: горизонтального скролла нет. Проверены мобильное меню, якорный переход через pinned-секцию, локальное открытие диагностического PNG, масштаб 125%, выключение света студии, сброс, открытие галереи и закрытие Escape с возвратом фокуса. После исправлений отсутствуют ошибки и предупреждения консоли. Диагностическое изображение не включено в проект.

Режим reduced motion реализован через CSS media query и `gsap.matchMedia`; переключение системной настройки на физическом устройстве не тестировалось. Точное кадрирование и визуальное соответствие автомобилю не проверены из-за отсутствия исходного фото.

## Источники и ограничения

Фотографии: не предоставлены, сторонние автомобильные изображения не использованы. Иконка вкладки — оригинальная типографическая буква O, не эмблема Škoda. Шрифты: [Manrope](https://github.com/google/fonts/tree/main/ofl/manrope), [Oswald](https://github.com/google/fonts/tree/main/ofl/oswald), SIL Open Font License (лицензии в `public/fonts`).

Применены установленные навыки `build-awwwards-quality-sites`, `frontend-design`, `cinematic-gsap-lenis-motion-system`, `gsap-react`, `gsap-scrolltrigger`. Интеграция проверена по официальным [GSAP matchMedia](https://gsap.com/docs/v3/GSAP/gsap.matchMedia()/) и [Lenis](https://github.com/darkroomengineering/lenis).

Перед финальной публикацией добавьте настоящее фото автомобиля и проверьте кадрирование, координаты подписей и соответствие внешности. Студийное появление контуров и отражений, а также непрерывное пространственное вращение нельзя достоверно получить из отсутствующего снимка или одного ракурса: этот проект использует честные фотографические переходы.
